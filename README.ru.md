# GTASADE PC Fix

Исправления ПК-версии **Grand Theft Auto: San Andreas – The Definitive Edition**: raw-мышь для
камеры и лимит FPS, который не слетает. Дальше планируется больше.

*Раньше назывался «GTASADE Raw Mouse Fix» (`SADE.HighFpsRawMouseFix`).*

**[⬇ Скачать последний релиз](https://github.com/Bryntsev/GTASADE-PCFix/releases/latest)**
(файл `.zip` в разделе *Assets*) · [English version](README.md)

## Что делает мод

- **Raw-мышь для камеры.** Ремастер превращает движение мыши во что-то вроде стика геймпада: камера
  двигается ступеньками, медленно или неровно, особенно по вертикали, при высоком FPS и высокой
  частоте опроса мыши. Мод передаёт камере настоящее движение мыши с полной частотой опроса
  (проверено на 1000 Гц), без ускорения и без потерь. В меню остаётся обычный курсор Windows.
- **Лимит FPS, который не слетает.** Игра сбрасывает свою настройку FPS на 60 при каждом запуске
  (и без модов). Мод держит выбранный лимит: по умолчанию **120**, это максимум, при котором ещё нет
  глюков анимации ремастера.
- **Панель настроек и информация поверх игры** (с ReShade): чувствительность, вкл/выкл, лимит FPS
  и небольшое окно с источником мыши, частотой опроса и временем кадра.

Мод не использует `SendInput`, ничего не автоматизирует и не меняет файлы игры на диске.

## На чём проверено

| | |
|---|---|
| Игра | Steam, `SanAndreas.exe` **1.0.113.21181** (Steam build 16391096) |
| ОС | Windows 11 |
| Обязательно | [Fusion Fix](https://github.com/ThirteenAG/WidescreenFixesPack/releases/tag/gtasade) (настройки по умолчанию, в комплекте Ultimate ASI Loader 9.7.0) |
| По желанию | ReShade 6.8.0 с поддержкой аддонов (поставлен через [RHI](https://github.com/RankFTW/RHI)), RenoDX, NVIDIA Smooth Motion |
| Мышь | частота опроса 1000 Гц |

На неизвестной версии игры мод не включается (это видно в логе), чтобы не уронить игру. Тогда
нужно обновление мода.

## Установка

Сначала закройте игру. Оба архива ниже повторяют структуру папки игры: распакуйте их в **папку
игры**, ту, где лежит папка `Gameface` (Steam: ПКМ по игре → *Управление* → *Просмотреть локальные
файлы*), с заменой файлов.

### 1. Fusion Fix (обязательно)

Скачайте **`GTASADE.FusionFix.zip`** со страницы
[Fusion Fix для GTA SA DE](https://github.com/ThirteenAG/WidescreenFixesPack/releases/tag/gtasade)
([страница проекта](https://thirteenag.github.io/wfp#gtasade)) и распакуйте в папку игры.

Почему обязательно: этот мод исправляет то, как движение мыши доходит до камеры. А то, как камера
потом себя ведёт (прежде всего вертикальная ось, а также автовозврат за спину и камера пешком), —
это логика камеры самой игры, и её исправляет Fusion Fix (`ImproveCameraPC = 1` в
`scripts\GTASADE.FusionFix.ini`, включено по умолчанию). Без него вертикальная ось всё равно
ощущается неправильно. Заодно он ставит Ultimate ASI Loader (`version.dll`), который загружает этот мод.

### 2. GTASADE PC Fix

Распакуйте **`GTASADE-PCFix-v0.2.0.zip`** в папку игры. Должно получиться:

```text
Gameface\Binaries\Win64\GTASADE.PCFix.addon64
Gameface\Binaries\Win64\scripts\GTASADE.PCFix.asi
Gameface\Binaries\Win64\scripts\GTASADE.PCFix.RawInputHelper.exe
Gameface\Binaries\Win64\scripts\GTASADE.PCFix.ini
```

`.asi` должен лежать именно в `scripts`: `.asi` прямо в `Win64` вызывал падение игры при запуске
вместе с ASI Loader, ReShade и оверлеем Steam.

**Обновляетесь с v0.1.0 («Raw Mouse Fix»)?** Сначала удалите старые файлы:
`scripts\SADE.HighFpsRawMouseFix.asi`, `.RawInputCompanion.exe`, `.ini` и старые логи
`SADE.HighFpsRawMouseFix_*.log` / `.csv`. Если старая версия останется, новая не включится и
напишет об этом в лог.

### 3. ReShade (по желанию, рекомендуется)

Даёт панель настроек, окно информации поверх игры и горячие клавиши. Исправление мыши и лимит FPS
работают и без него.

- Проще всего через [RHI](https://github.com/RankFTW/RHI) (ReShade HDR Installer): ставится для
  игры в пару кликов. Мод проверялся именно так.
- Или официальным установщиком с [reshade.me](https://reshade.me): скачайте версию **with full
  add-on support**, выберите `Gameface\Binaries\Win64\SanAndreas.exe`, API DirectX 10/11/12.

ReShade сам загрузит `GTASADE.PCFix.addon64`.

### Если не заработало

Добавьте параметр запуска Steam `-dx12` (игра → *Свойства* → *Параметры запуска*). Мод проверялся
в DirectX 12.

## Как проверить, что мод работает

1. Запустите игру, загрузите сохранение и поиграйте секунд 20 (хуки камеры включаются примерно
   через 15 секунд после запуска).
2. Откройте `Gameface\Binaries\Win64\scripts\GTASADE.PCFix.log`. В нём должна быть строка:

   ```text
   RAW MOUSE FIX ACTIVE
   ```

3. С ReShade: клавиша **Home** → вкладка **Add-ons** (Дополнения) → **GTASADE PC Fix**.
   *Game build*, *Core*, *Raw Input helper* и *Camera hooks* должны быть зелёными. Включите
   **Show mouse info over the game**: при движении мыши в игре должно быть
   `Mouse: game process ~1000 Hz` (или частота опроса вашей мыши).

## Настройки по умолчанию и как их менять

| Настройка | По умолчанию | Где менять |
|---|---|---|
| Raw-мышь для камеры | Вкл | панель, `Ctrl+End`, ini `[Mouse] Enabled` |
| Чувствительность X / Y | 1.00 / 1.00 | панель (ползунок или точное число), ini `SensitivityX` / `SensitivityY` |
| Лимит FPS | 120 | панель, `Ctrl+PgUp` / `Ctrl+PgDn`, ini `[Game] MaxFps` |
| Окно информации | Выкл | панель, `Ctrl+Insert` |
| Логи для разработчика | Выкл | панель → *Developer*, ini `[Developer] Enabled` |

Панель = меню ReShade (**Home**) → *Add-ons* → *GTASADE PC Fix*. Изменения применяются сразу.
Лимит FPS сохраняется автоматически; чтобы чувствительность и вкл/выкл сохранились до следующего
запуска, нажмите *Save to ini*.

`MaxFps`: `0` — выключено (решает игра), `-1` — без лимита, иначе 30 / 60 / 90 / 120 / 180 / 240.
Лимит применяется через несколько секунд после запуска и снова сразу после входа в Rockstar, где
игра его сбрасывает.

Горячие клавиши (нужен ReShade, окно игры активно):

| Клавиши | Действие |
|---|---|
| `Ctrl+PgUp` / `Ctrl+PgDn` | Лимит FPS: Off → 30 → 60 → 90 → 120 → 180 → 240 → Unlimited |
| `Ctrl+End` | Raw-мышь вкл/выкл (сравнить с родной мышью игры) |
| `Ctrl+Insert` | Показать/скрыть окно информации |

Окно информации можно перетащить мышью, пока открыто меню ReShade.

## Удаление

Закройте игру и удалите четыре файла выше и `scripts\GTASADE.PCFix.log`. ReShade или ASI Loader можно оставить или удалить отдельно.

## Совместимость

- **Fusion Fix** (обязательно), **ReShade / RenoDX** (через RHI), **NVIDIA Smooth Motion**: работают вместе.
- **Разблокировщики MFG для RTX 40** (RTXMFG, MFGAdaUnlock): загружаются без конфликтов, но в этой
  игре ничего не дают, потому что в ней нет встроенного DLSS Frame Generation, который они расширяют.
- Только для одиночной игры. Не используйте моды в онлайн-играх и играх с античитом.

## Известные особенности

- Исправление камеры включается примерно через 15 секунд после запуска игры.
- В меню паузы выделение возвращается на открытую вкладку, когда курсор уходит с пунктов, — это
  поведение самой игры.
- Редкие подвисания кадров — от игры/движка, а не от мыши (одинаково часто с движением мыши и без).
- Глюки анимации выше 120 FPS — баг ремастера; лимит по умолчанию их обходит.
- С ReShade и оверлеем Steam игра иногда не запускается (ошибка лаунчера Rockstar «Не удалось
  запустить игру»); такое бывало и без мода. Запустите ещё раз; если повторяется — отключите оверлей
  Steam для игры.

## Как это работает, коротко

Камера игры каждый кадр читает позицию курсора. Мод отвечает на эти чтения настоящим движением
мыши, накопленным с прошлого кадра. Windows 11 ограничивает Raw Input для фоновых процессов
примерно 125 Гц, поэтому мод читает мышь внутри процесса игры, а маленький `.exe`-помощник
использует только как запасной вариант.

## Антивирусы

Мод — неподписанный плагин, который перехватывает функции процесса игры, плюс `.exe`-помощник и
общая память между ними. Такое сочетание может вызывать эвристические срабатывания. Скачивайте
только с этой страницы, сверяйте SHA256 и смотрите ссылку на VirusTotal в описании релиза.
Исходный код открыт, мод можно собрать самостоятельно.

## Проблемы и обратная связь

Создайте [issue](https://github.com/Bryntsev/GTASADE-PCFix/issues) и приложите:

- `Gameface\Binaries\Win64\scripts\GTASADE.PCFix.log`
- при проблемах с мышью: включите *Developer mode* в панели (или `[Developer] Enabled=1` в ini),
  перезапустите игру, повторите проблему и заархивируйте самую новую папку из
  `Gameface\Binaries\Win64\scripts\GTASADE.PCFix_logs`.
